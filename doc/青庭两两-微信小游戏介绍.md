# 青庭两两 · 微信小游戏介绍

> 本文档基于当前仓库代码（Cocos Creator 3.8.x + TypeScript）整理，用于微信小游戏上架、运营文案与对外说明。  
> 技术栈：竖屏 2D 连连看，入口脚本 `GameApp`，棋盘 `LinkUpBoard`（8×14 格）。

## 一、产品定位

| 项目 | 内容 |
|------|------|
| **中文名** | 青庭两两 |
| **类型** | 休闲益智 · 连连看 |
| **平台** | 微信小游戏（竖屏） |
| **核心体验** | 经典两两消除 + 关卡递进机制 + 卡组收集养成 |
| **目标用户** | 喜欢轻松消除、短时游玩的全年龄段休闲玩家 |

## 二、游戏主界面风格

整体视觉为 **法式庭院下午茶** 主题：竖屏休闲界面，首页与对局页共用同一套明亮、手绘感的美术语言，营造「阳光洒在草地上、悠闲享用下午茶」的浪漫氛围。

### 2.1 线条与轮廓（灵魂所在）

- **深色勾线**：最显著的特征。所有物体的边缘都有清晰、流畅的深褐色或深灰色线条勾勒，类似于钢笔淡彩或复古漫画的描边，让画面非常有结构感和精致度。
- **粗细变化**：线条不是死板的，在轮廓处稍粗、细节处变细，增加了手绘的生动感。

### 2.2 色彩体系（温馨来源）

- **高明度、低对比**：整体颜色非常明亮、柔和。大量的奶油白、淡黄色、嫩草绿，给人一种温暖、阳光明媚的感觉。
- **复古点缀色**：桌椅的金色雕花、陶土花盆的红褐、茶具的粉蓝，这些颜色虽然鲜艳但并不突兀，反而增添了古典的贵气。

### 2.3 质感与光影（立体来源）

- **平涂 + 轻微阴影**：色块填充比较平整，但在物体下方（如椅子腿、桌底、花盆下）加了柔和的灰色阴影，让物体有了重量感和立体感，稳稳地落在草地上。
- **细腻的纹理**：虽然是平涂，但能感觉到类似水彩纸的细微吸色感，不油腻。

### 2.4 题材元素（浪漫来源）

- **法式家具**：带有雕花的欧式桌椅（路易十六风格），铺着蕾丝花边的桌布。
- **下午茶道具**：精致的茶壶、茶杯、马卡龙/点心盘，象征着悠闲的时光。
- **繁茂植物**：爬藤月季、盛开的天竺葵、茉莉花，充满生命力。

界面布局上，首页以庭院场景为背景，「开始游戏」「商店」「配置卡组」等入口融入场景元素；对局页顶栏展示关卡数，中央为棋盘区，底栏为提示 / 刷新 / 消除三枚道具按钮，整体与背景风格统一。

## 三、具体玩法

《青庭两两》的核心是 **经典连连看 + 关卡递进**，操作简单、单局时长适中，适合碎片时间游玩。

### 3.1 基本目标

在 **8 列 × 14 行** 的棋盘上，点击两个 **相同图案** 的方块；若二者之间能通过空格走通，且路径拐弯次数 **不超过 2 次**，即可消除这一对。当场上所有方块被清空，即 **通关**，进入结算并解锁下一关。

### 3.2 操作技巧

| 操作 | 说明 |
|------|------|
| 单击方块 | 选中；再点另一同类型且可连线的块 → 消除 |
| 再次单击已选块 | 取消选中 |
| 选中两个同类型但不可连 | 两格轻微摇晃，提示路径不通 |
| 双击某一格 | 场上 **所有同类型** 方块一齐摇晃，便于辨认 |

连线成功时，会出现 **金线闪烁**、**星星沿路径散开** 等特效，并播放消除音效，反馈清晰爽快。

### 3.3 开局与僵局

- **发牌动画**：进入关卡后，方块从上往下、从左往右逐格落下，营造发牌体感；发牌期间暂不可操作。
- **自动刷新**：若场上已无任何可连线的一对，会提示并 **自动重排** 棋子，尽量保证至少存在一对可连块，避免死局。

### 3.4 局内辅助

底栏提供三种道具（可在商店用金币购买）：

| 道具 | 作用 |
|------|------|
| **提示** | 高亮一对可连线方块，约 2 秒 |
| **刷新** | 保留现有图案类型，随机重排位置 |
| **消除** | 优先消除场上同类型的两个方块 |

### 3.5 关卡进阶 · 消除后靠齐

从第 2 关起，每消除一对，同行或同列剩余方块会向指定方向 **靠齐**，增加策略深度：

| 关卡 | 靠齐方向 |
|------|----------|
| 第 1 关 | 无靠齐，标准连连看 |
| 第 2 关 | 向左 |
| 第 3 关 | 向右 |
| 第 4 关 | 向上 |
| 第 5 关 | 向下 |
| 第 6 关起 | 四向之一（按关卡固定，同关重开方向不变） |

进入相应关卡时，屏幕会 Toast 提示本关机制；靠齐过程带有位移动画，手感 Q 弹。

## 四、系统功能

游戏以 **本地单机 + 本地存档** 为主，围绕「闯关 → 赚金币 → 养成盘面」形成闭环。主要系统如下。

### 4.1 金币系统

- **获取**：通关结算时，奖励金币数 = **本关成功连线次数**（连得越多，赚得越多）。
- **消耗**：在商店购买方块（**10 金币/块**）、购买局内道具（**50 金币/个**）。
- **展示**：首页与商店顶部实时显示当前金币；金币与进度一并 **本地持久化**，随时续玩。

### 4.2 商城系统

- **入口**：首页「商店」按钮，弹出商店弹窗。
- **商品分类**：陆地动物、水生动物、水果、零食、蔬菜、面点等主题方块，按分组一页展示；顶部同时陈列 **提示 / 刷新 / 消除** 三种道具。
- **购买规则**：仅 **已购买** 的方块可在卡组中选用；新玩家各分组初始赠送若干种方块。购买成功写入「已拥有」状态。

### 4.3 道具系统

- **种类**：提示、刷新、消除，对应局内底栏三按钮。
- **库存**：每种道具独立计数，使用后扣减；库存不足时提示前往商店购买。
- **价格**：商店内 **50 金币/个**；测试模式下可配置为无限使用，便于调试。

### 4.4 卡组配置（养成向）

- **入口**：首页「配置卡组」。
- **规则**：从已购方块中勾选 **30～40 种** 作为本局盘面图案；未购不可选。配置保存本地。
- **开局条件**：卡组至少 **30 种** 方可点击「开始游戏」，保证盘面图案丰富度。

### 4.5 关卡与进度

- 当前关卡号本地保存，通关后自动进入下一关。
- 支持 **返回首页** 与 **下一关** 结算选项；可选 BGM、通关庆祝动画与音效，增强完成感。

## 六、玩法说明（基于代码实现）

### 6.1 基本规则

1. **棋盘**：固定 `8` 列 × `14` 行，共 `112` 格（`LinkUpBoard.BOARD_COLS` / `BOARD_ROWS`）。
2. **消除条件**：点击两个**相同类型**的方块；二者之间须存在一条路径，路径只能在**空格**上走，且拐弯次数 **≤ 2**（`LinkUpPathFinder`）。
3. **胜利条件**：场上所有方块被消除后触发通关（`onWin` → 结算页）。
4. **关卡进度**：当前关卡号保存在本地（`linkup_v1_current_level`），通关后自动进入下一关。

### 6.2 操作与反馈

| 操作 | 效果 |
|------|------|
| 单击方块 | 选中；再次点另一同类型且可连线的块 → 消除 |
| 单击已选中的同格 | 取消选中 |
| 选中两个同类型但不可连 | 两格轻微摇晃 |
| 双击某一格 | 场上**所有同类型**方块一齐摇晃（辅助辨认） |
| 选中瞬间 | 轻微放大再缩回 + 可选选中音效 |

连线成功时：绘制金线（约 0.5 秒）、星星沿路径 burst 散开渐隐、播放连线消除音效。

### 6.3 局内道具（底栏三按钮）

道具可在商店用金币购买（**50 金币/个**），通关奖励金币；库存本地持久化。测试模式下可无限使用。

| 道具 | 行为（代码） |
|------|----------------|
| **提示** | `showHint()`：高亮一对可连线方块约 2 秒 |
| **刷新** | `shuffleAll(true)`：保留现有棋子类型，随机重排位置，并尽量保证至少一对可连 |
| **消除** | `removeTwoRandomTiles()`：**优先**消除场上同类型的两个；若无同类型则随机消两个；播放与连线相同的消除音效 |

### 6.4 僵局处理

当检测到场上**没有任何可连线的一对**时（`hasAnyConnectablePair()`）：

- 弹出可配置文案（默认：「场上没有可连线方块，自动刷新」）；
- 延迟后自动执行刷新（`shuffleAll(true)`），避免死局。

### 6.5 关卡机制 · 消除后靠齐

| 关卡 | 机制 |
|------|------|
| 第 1 关 | 标准连连看，无靠齐 |
| 第 2 关 | 消除后，同行剩余方块 **向左** 靠齐 |
| 第 3 关 | **向右** 靠齐 |
| 第 4 关 | **向上** 靠齐 |
| 第 5 关 | **向下** 靠齐 |
| 第 6 关起 | 四向靠齐 **按关卡号伪随机** 其一（同关重开方向不变） |

进入第 2 关及以后时，屏幕中央 Toast 展示对应机制说明（`getLevelEnterTip`）。靠齐过程有约 0.5 秒位移动画（带回弹感）。

### 6.6 发牌与开局

进入关卡后，方块按 **从上往下、从左往右** 逐格落下（`DEAL_INTERVAL` / `DEAL_DROP_DURATION`），营造发牌体感，发牌期间不可操作。

### 6.7 首页与经济系统

**首页（`HomeView`）**

- 开始游戏（需卡组 ≥ 30 种已购方块方可开局）；
- 配置卡组、商店；
- 展示当前金币数量。

**金币**

- 通关结算：奖励 = **本关成功连线次数**（`addCoins(connectCount)`）；
- 用途：商店购买方块（**10 金币/块**）、购买道具（**50 金币/个**）。

**商店（`ShopDialog`）**

方块按分组展示（在 `GameApp` 配置贴图后生效）：

- 陆地动物、水生动物、水果、零食、蔬菜、面点等；
- 购买后写入「已拥有」，方可在卡组中选择。

**卡组（`DeckSelectDialog`）**

- 从已购方块中勾选 **30～40** 种作为本局盘面图案；
- 未购方块不可选；配置保存本地。

### 6.8 通关结算

- 弹窗高度约为画面一半、宽度约三分之二；
- 展示本关获得金币；
- **返回首页** / **下一关**；
- 可配置：弹窗背景、按钮贴图、通关音效、画面上半区循环庆祝动画帧。

### 6.9 音频与界面（可配置）

在 **App → GameApp** 组件可配置：

- 首页/游戏页背景、页眉背景图；
- BGM（启动后循环；时长 >10 秒时从第 10 秒起播）；
- 连线、选中、提示、刷新、消除、通关等音效；
- 各类按钮与方块贴图。

游戏页顶栏居中显示**关卡数字**（白字黑边）；底栏为提示 / 刷新 / 消除三按钮。

## 七、项目结构（便于审核/协作）

```
assets/Scripts/
├── GameApp.ts          # 入口：首页↔游戏、商店/卡组、资源注入
├── game/
│   ├── HomeView.ts     # 首页
│   ├── GameView.ts     # 游戏 UI、道具、结算入口
│   ├── LinkUpBoard.ts  # 棋盘逻辑、靠齐、发牌、特效
│   ├── LinkUpPathFinder.ts  # 连线判定（≤2 拐）
│   ├── ShopDialog.ts   # 商店
│   ├── DeckSelectDialog.ts  # 卡组
│   └── LevelClearOverlay.ts # 通关结算
└── util/
    ├── PlayerResourceStorage.ts  # 金币、关卡、道具、已购
    ├── DeckSelectionStorage.ts   # 卡组存档
    └── ShopCatalog.ts            # 商店目录
```

本地存储键前缀：`linkup_v1_*`（微信小游戏内使用 `sys.localStorage`）。
