# 连连看 MVP — 节点路径（Cocos 场景）

在 **一个 2D 场景** 中只需手动放置最简节点；其余 UI 由 `GameApp` 在运行时创建。

## 场景根

| 节点 | 路径 | 说明 |
|------|------|------|
| Canvas | `/Canvas` | 2D 根画布，设计分辨率建议 720×1280（竖屏） |
| App | `/Canvas/App` | 空节点，挂 `GameApp` 组件 |

## 运行时自动创建的子树（供对照与调试）

脚本会在 `/Canvas/App` 下创建：

| 路径 | 说明 |
|------|------|
| `/Canvas/App/HomeRoot` | 首页：背景、上传区、开始按钮 |
| `/Canvas/App/GameRoot` | 游戏页：顶栏、棋盘、底栏按钮 |

加载 `assets/resources` 下贴图时，使用 `resources.load('...', SpriteFrame)`，路径相对于 `resources` 文件夹、**不含** `resources/` 前缀与扩展名。
