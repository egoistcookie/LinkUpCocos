# 连连看 MVP — 节点路径（Cocos 场景）

本工程 **不要求** 在编辑器里搭完整 UI；**首页 / 游戏页 / 棋盘** 均由脚本在运行时创建。  
你只需要保证场景里有 **摄像机 + 挂 `GameApp` 的入口节点**。

---

## 一、编辑器里「必须」有的（最少配置）

| 序号 | 节点名（建议） | 父节点 | 必须组件 / 说明 |
|------|----------------|--------|------------------|
| 1 | **scene**（或任意场景根） | — | Creator 默认场景根 |
| 2 | **Main Camera** | `scene` 根下 | **不要删**。带 `Camera`，负责把画面画到屏幕（清屏色等）。 |
| 3 | **App** | `scene` 根下即可 | 添加自定义脚本 **`GameApp`**。可选：在 **Home Background** 拖一张 `SpriteFrame` 作首页默认底图；不拖则为白底。 |

**注意：**

- **不需要** 在编辑器里手动创建「开始游戏」按钮、Label、棋盘格子等，这些由 `GameApp` → `HomeView` / `GameView` 代码生成。
- 层级里 **暂时看不到 `Canvas`** 是正常的：`GameApp` 在 **游戏运行（预览）** 时若没有 `Canvas`，会 **自动创建 `Canvas` 并把 `App` 挪到其下**。你在编辑器里保存的场景文件里可能仍是「`App` 与 `Main Camera` 平级」，**不影响预览**。

---

## 二、编辑器里「可选」但推荐（与内置 2D 工程一致）

若希望 **一打开场景** 在层级里就看到完整 UI 结构、方便排查：

| 序号 | 节点名 | 父节点 | 说明 |
|------|--------|--------|------|
| 1 | **Canvas** | `scene` 根下 | 添加 **`Canvas`** 组件；设计分辨率与项目设置一致（如 720×1280）。 |
| 2 | **App** | 放在 **`Canvas` 子级** | 同样只挂 **`GameApp`**。`GameApp` 发现已在 `Canvas` 下时 **不会** 再移动父节点。 |

可选：在 `Canvas` 下再放 **`UICamera`（带 Camera）** 并绑定到 Canvas 的 Target Camera——**本仓库脚本也会在运行时补全 UICamera**，故非必须。

---

## 三、运行时自动创建（不要手搓同名去顶替）

以下仅在 **点击预览 / 真机运行** 后出现，**不必**在编辑器里预先创建：

| 路径（运行时） | 说明 |
|----------------|------|
| `/Canvas` | 仅当场景里 **没有** 名为 `Canvas` 的节点时由 `GameApp` 创建。 |
| `/Canvas/UICamera` | 带正交 `Camera`，供 UI 使用（与「屏幕空间 - 摄像机」配套）。 |
| `/Canvas/App` | `App` 被挂到 `Canvas` 下后的路径。 |
| `/Canvas/App/HomeRoot` | 首页：背景、上传、开始游戏等。 |
| `/Canvas/App/GameRoot` | 游戏页：顶栏、棋盘、底栏。 |

---

## 四、协同与版本管理（和「有没有节点」无关但必须做对）

- **`assets` 下所有 `.meta`** 与场景、脚本 **一起提交 Git**，否则 UUID 不一致会导致引用丢失、脚本报错或白屏。
- **`settings/`**（含 `v2`）建议提交；**`library/`、`temp/`、`profiles/`** 一般不要提交（见项目 `.gitignore` 与 `doc/Cocos配置与预览.md`）。

---

## 五、`resources` 动态加载路径

使用 `resources.load('...', SpriteFrame)` 时，路径相对于 **`assets/resources/`** 文件夹，**不含** `resources/` 前缀与扩展名。
